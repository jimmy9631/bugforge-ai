# 🐞 BugForge AI

AI-powered bug bounty report generator built with Python, Streamlit, and OpenAI.

## 🚀 Features

- Generate professional bug bounty reports
- Support for common vulnerability types
- Simple Streamlit interface
- Markdown report output
- Download generated reports
- Environment-based API key configuration

## 🛠️ Tech Stack

- Python
- Streamlit
- OpenAI API
- python-dotenv

## ⚙️ Installation

Clone the repository:

```git clone https://github.com/jimmy9631/bugforge-ai.git```

```cd bugforge-ai```

Create a virtual environment:

```python -m venv venv```

Activate it and install dependencies:

```pip install -r requirements.txt```

Create a `.env` file:

OPENAI_API_KEY=your_api_key_here

Run:

```streamlit run app.py```
